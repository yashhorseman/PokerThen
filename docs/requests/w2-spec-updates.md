# W2: SPEC updates from live research 08 (applied in the engine; please fold into SPEC)
- No Main/Side pot labels: frame has one `hand.pot` + bets; log has one `collected` line per pot per run, main pot first, run 1 lines then run 2 lines.
- RIT odd chip: pot halves per run, odd chip to run 1 (1005 -> 503/502). 3-way chop of 33 = 11 each. Two-way tied odd chip still U-D5 (placeholder: first winner left of dealer).
- Short all-in (less than a full raise): prior actors cannot raise (`hand.noReraiseIds`), the next min-raise-to = highest + the short shove's increment (160 + 60 = 220), a full raise (increment >= last increment) reopens for everybody.
- Rebuy (busted players only, Allow Rebuy on): at next-hand time log `Asking to busted players the rebuy decision.`, 20 s shared window (REBUY_WINDOW_SEC, was a 30 s placeholder), `The player X requested a rebuy of N.`, owner approval with own stack, `The player X rebought. New stack N.` before `Player stacks:`; cancel/timeout/deny -> `The player X quits the game with a stack of 0.` Cancel = action QNH.
- Time bank refills bankLength/N per hand dealt in (cap bankLength). Server acts at the no-bank deadline (+1.5 s grace) unless the client sent ATB.
- Antes: `X posts an ante of 5` for every player in seat order before blinds, dead money to the pot, not part of call/min-raise amounts, header `(A:5)` (frame `table.blinds.ante`), `The game's ante was changed from 0 to 5.` at hand start.
- No log line for pause/resume or away/back (the `stand up` line at hand end stays). Owner stack change mid-hand: `WARNING: the admin queued the stack change for the player X adding N chips in the next hand.` (SET: `reseting to N chips`), applied + `The admin updated the player X stack from A to B.` at next hand start. Remove player: `The admin X enqueued the removal of the player Y.` then `The player Y quits the game with a stack of N.`
- Rabbit hunt: only missing cards offered; `Undealt cards: <board> [new]` (empty board -> two spaces) logged ONLY for the requester (onlyFor); each click extends the window by 3 s.
- Config changes mid-hand: logged as one `Game Config Changes` block (lines `* Name: old » new`, names per 08 i) at next hand start; Allow Straddle and Showdown Speed apply at once (block logged immediately).
- Combination order in `collected` lines: groups ascending by (count, rank): kickers low to high, then pairs, then trips; among equal ranks the LAST dealt card is used (straight example 6♣ not 6♥).
- Spectator Mode precondition: the owner is seated from creation, so "only while nobody is seated" is unsatisfiable; the engine requires table status `waiting`.
