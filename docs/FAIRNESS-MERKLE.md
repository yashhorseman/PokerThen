# FAIRNESS-MERKLE.md - owner-approved fairness design (SUPERSEDES SPEC 20.2-20.4 and ARCHITECTURE 11/14.4-R1 where they conflict)

Owner decision (2026-10-26): **per-card Merkle proof**. After a hand, ONLY cards that were actually exposed during that hand are revealed, each with a proof that it sat at a given position of the deck committed BEFORE the hand. Mucked / folded hole cards, burn cards and undealt cards are never published. Nothing else about the PokerNow clone changes; the visible footprint is the two dimmed log lines + `/verify` page.

## Construction (all hashes SHA-256, lowercase hex, UTF-8 strings joined with `|`)
1. At hand start the engine draws `deck[0..51]` (Fisher-Yates, rejection sampling) and a 32-byte `masterSalt` (independent entropy draw).
2. Per-card salt: `salt[i] = SHA256("PT1S|" + masterSalt + "|" + i)`.
3. Leaf: `leaf[i] = SHA256("PT1L|" + gameId + "|" + handNo + "|" + handId + "|" + i + "|" + card[i] + "|" + salt[i])` where `card` is the canonical 2-char code used elsewhere (e.g. `As`, `Td`).
4. Merkle tree over the 52 leaves in index order, padded to 64 leaves with `leaf = SHA256("PT1PAD")`; node = `SHA256("PT1N|" + left + "|" + right)`; `root` = top node.
5. `commitment = SHA256("PT1C|" + gameId + "|" + handNo + "|" + handId + "|" + prevCommitment + "|" + root)`; `prevCommitment` is the previous hand's commitment of the same table (64 zeros for the first hand). Chain => an earlier commitment cannot be altered later.
6. **Commit** (published in the hand log line before any hole card is visible to anyone, and stored in fairness.jsonl): `{gameId, handNo, handId, prevCommitment, root, commitment}`.
7. **Deal map**: the deck position of each exposed card is deterministic (SPEC 20.3: hole cards, burn, flop/turn/river, run-2 positions). The reveal states which index went where (e.g. `hole:<playerId>:<k> -> i`, `flop -> [i,i,i]`, `burn -> i` positions only, never the burn card value unless it was exposed).
8. **Reveal** (published when the result window closes, as SPEC 20.4 timing): for every card that was exposed to ANY viewer during the hand (board cards, run-2 cards, hole cards shown at showdown/all-in reveal/voluntary SHOW_HAND, rabbit cards shown to at least one requester) emit `{index, card, salt, proof:[sibling hashes bottom-up]}`. Cards never exposed are absent. The hand's `usage` map (which index was dealt to whom, including indices of mucked hole cards WITHOUT card values) is published so a verifier can check that revealed cards are consistent with the log (e.g. board shown in the log equals revealed board indices).
9. **Verify** (browser `/verify`, CLI `scripts/verify-hand.ts`, shared `verifyReveal`): recompute each revealed leaf from (gameId, handNo, handId, index, card, salt), fold the proof up to `root`, recompute `commitment` from `prevCommitment`+`root`, compare to the commitment printed in the log BEFORE the hand; check the previous hand's commitment equals `prevCommitment`; check revealed cards match the cards in the hand log and that no card index is revealed twice with different values; PASS/FAIL with reasons. Also expose "chain check" across hands.
10. Honest limits (show on /verify in one short paragraph): the proof shows the deck order was fixed before anyone saw cards and that every revealed card came from it; it cannot by itself prove the shuffle was uniformly random - that is guaranteed by the open-source Fisher-Yates + rejection-sampling code and its tests.
