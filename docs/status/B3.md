## Bugs fixed (engine)
1. frame `turn.rebuy.requests` listed every busted id with `null` from the start, so the client's `youId in requests` made `youDecide` false: the busted player NEVER got the `Would you like to Rebuy?` modal in a browser. Now only pending non-null requests are projected (packages/engine/src/frame.ts).
2. Leave seat / Away / queued removal pressed while the action is ON that player did nothing until the timer ran out. Check/fold mode now starts immediately (`autoIfActor`, flow.ts + commands.ts; unit test added in admin.test.ts).
3. Granted spectators (god mode) were never included in `players` for other viewers (a `&& false` leftover), so the client's `N seeing the hole cards` counter stayed 0 and the warning modal printed ids. They are now projected (name+id).

- b3-11 blind levels 10/20 (1 min) -> 20/40: `NEXT BLIND: 20/40 IN 00:58` header text, level applied at a hand start after the minute, new blinds posted, header 20 / 40, no level-change log line (none in research, U-G6). ~65 s.
